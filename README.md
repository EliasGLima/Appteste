# 📺 Buscador de Vídeos por Hashtag no YouTube

App simples feito com Python + Streamlit que busca vídeos do YouTube com base em uma hashtag.

## Como usar

1. Insira sua API Key no menu de segredos do Streamlit Cloud
2. Digite uma hashtag
3. Veja os vídeos encontrados com essa hashtag

Feito com ❤️ e inteligência artificial.
